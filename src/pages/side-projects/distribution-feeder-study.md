> **Sample concept:** This is a project prompt, not a report of completed work or measured results.

## The question

How do demand growth and distributed generation affect voltage and equipment loading along a representative radial feeder?



## A possible approach

Build a clearly documented sample feeder model, state all assumed line, transformer, and load data, then compare a base case with a small set of changed operating conditions. Record the assumptions beside each result so another engineer can reproduce the exercise.

## Example deliverables

- A one-line diagram and a table of assumed network data.
- Base-case and sensitivity-case load-flow summaries.
- A short note on voltage limits, thermal loading, and model limitations.

Use verified network data, an appropriate study tool, and applicable utility criteria before treating any findings as engineering advice.
